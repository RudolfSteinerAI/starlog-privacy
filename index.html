STARLOG privacy policy

Package com.starlog.app · Local-first personal log

This is the public copy of the in-app policy. Host it on a stable URL before Play Console review (GitHub Pages, your site, or a Google Doc set to public).

STARLOG is a personal log. It is local-first.

What stays on the device

Log text, tags, classification, stardate, PIN hash, officer/vessel name, audio, and video are stored only in the app's private storage. There is no STARLOG account and no STARLOG cloud.

What never happens

We do not sell data. We do not run ads. We do not upload logs. Android backup and device-to-device transfer of app data are disabled.

Permissions

  • Microphone — only when the user taps Record Audio, Record Video, or Dictate.
  • Camera — only when the user taps Record Video.
  • Speech recognition — only when the user taps Dictate. On some devices the OS may use an on-device or vendor speech service. STARLOG does not send that audio to a STARLOG server.

Export and share

JSON copy, file export, and the system share sheet run only when the user taps them.

Lock

The optional PIN is hashed on device (SHA-256). STARLOG cannot recover a forgotten PIN.
